# Session report

Write it to the report file your brief names, then send it to the orchestrator.

- **Status:** DONE, DONE_WITH_CONCERNS, BLOCKED or NEEDS_CONTEXT.
- **Branch, full head SHA, PR number and CI state.**
- **Scope:** each item, done or not, with `path:line`.
- **Reuse:** what was reused; for each new file or larger function, why nothing existing could carry it.
- **Tests added:** each with the behaviour it catches, in one line, and its red-then-green proof.
- **Checks run:** each command and its result. The live check: entry point, steps, result and elapsed time, or why none applied.
- **Gate:** the `lc-gate status` table for your PR or step.
- **Docs updated:** stories, journeys, roadmap and glossary, or "no behaviour change".
- **Limits added:** none, or the list with the owner's decision.
- **Deviations, questions, and follow-ups filed as issues.**
